# Locket 隐私政策

生效日期：2026年10月8日。最后更新：2026年10月10日。

Reo Morishige(森重 玲生，“开发者”)下面描述了如何在Locket(“应用程序”)中处理信息。

## 1.概述

本应用可将抠出的照片、文字和手绘内容组合成小组件。照片处理和作品保存均在设备上完成。本应用不提供账号注册功能，也不会将照片、素材或作品发送到开发者运营的服务器。

该应用程序包括Google AdMob横幅广告和用于广告同意的Google用户消息平台(UMP)。计划提供付费无广告选项，目前无法购买。

## 2.您的设备上使用的信息

App在本地处理以下信息以提供其功能：

- 您选择或拍摄的照片，以及裁剪或剪切的图像，以创建、显示和编辑材料。

- 手绘图片和笔画数据，用于显示、编辑和重复使用手绘素材。

- 材料和文件夹名称、文本和设计设置（例如位置、颜色和样式），以管理材料并编辑或重新打开设计。

- 小部件图像和设置，以在主屏幕和锁定屏幕上显示设计。

- 在显示支持的效果时的设备运动，例如倾斜，以改变反射。运动不会保存为持续历史记录或发送给开发人员。

开发者无法查看或获取您设备上的应用程序中存储的照片、材料或设计。

## 3.存储和设备备份

应用程序数据存储在您的设备上。小部件图像和设置也存储在同一设备上的应用程序及其小部件扩展共享的应用程序组区域中。此共享不会向开发者发送信息。

该App没有独立的云同步或在线备份功能。根据您的设备设置和 Apple 的功能，可能会使用 iCloud 等服务进行设备备份，以及通过 iCloud 照片同步导出的照片。开发人员无权访问这些备份或您的照片库。

## 4. 照片、相机和动作权限

使用操作系统的照片选择器导入照片；该应用程序处理您选择的照片。当您选择拍照时，会使用相机；当您选择保存导出的设计时，会使用将图像添加到照片库的权限。设备倾斜用于支持材质效果。

权限是通过操作系统请求的并且可以在设备设置中改变。拒绝许可可能会导致相关功能无法运行。

## 5.外部连接和第三方服务

照片剪切在您的设备上进行处理。该应用程序与下述 Google 服务进行通信以获取广告和同意。没有集成单独的行为分析服务。

在应用程序内浏览器中打开使用条款或本政策会连接到 GitHub Pages。 GitHub 可能会处理 IP 地址、浏览器信息和其他访问信息以提供和保护网站。应用程序中存储的照片、材料和设计不会发送到这些页面。请参阅 [GitHub 的一般隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。

操作系统诊断、设备备份和照片同步根据您的设置和[Apple的隐私政策](https://www.apple.com/legal/privacy/en-ww/)进行处理。

## 6. Google AdMob 广告和同意

该应用程序使用 Google 移动广告 SDK 展示横幅广告，并根据您所在的地区和情况使用 Google UMP SDK 进行同意和隐私选择。广告出现在应用程序的界面内；它们不包含在主屏幕或锁定屏幕小部件中，也不包含在从应用程序保存或共享的图像中。

根据 SDK 设置、您的同意以及操作系统权限，IP 地址、设备和应用信息和标识符、广告展示和交互以及诊断等信息可能会发送给 Google。可以从 IP 地址推断出大致位置。该信息用于广告投放和衡量、欺诈预防、服务维护和改进以及同意管理。该应用程序不会将照片、剪纸材料、文本或设计内容或设备动作传递给广告 SDK。

当前实现请求非个性化广告并且不请求应用跟踪透明度许可或访问IDFA的许可。发布商第一方 ID 个性化已禁用。非个性化广告仍然涉及广告投放、衡量和预防欺诈所需的信息。

在启动时，应用程序向 UMP 请求更新的同意状态，并在需要时显示同意书。仅当 UMP 指示可以请求广告时，广告 SDK 才会启动。当需要隐私选择时，可以通过**设置→支持和法律→广告隐私设置**打开Goog​​le的隐私选项。更改同意或设置不一定会删除已传输的信息。

- [Google 隐私政策](https://policies.google.com/privacy?hl=en)

- [Google Mobile Ads SDK 的 iOS 数据披露说明](https://developers.google.com/admob/ios/privacy/data-disclosure)

- [个性化和非个性化广告](https://support.google.com/admob/answer/7676680?hl=en)

## 7. 计划的无广告选项的购买信息

计划通过Apple的App Store在引入无广告选项的版本中处理购买。 Apple 处理支付信息；开发商不获取信用卡号码。该应用程序预计将处理启用选项、验证购买状态和恢复购买所需的产品标识符和交易或权利信息。

选项的条件将在购买前显示。禁用广告不会删除已传输的广告信息，也不会停止 Apple 的购买处理、设备备份或类似服务。在引入购买之前，本政策将进行更新，以描述购买信息的实际实施存储和传输。

## 8.保存和共享图像

当您选择保存或共享图像时，图像将被传递到您选择的照片库或共享目的地。您和所选服务负责管理导出的图像及其在目的地的使用。

## 9.支持查询

如果您通过电子邮件联系我们，您的电子邮件地址、姓名（如果提供）、查询内容和附件将被处理以回复和解决问题。它们会在处理查询所需的时间内保留，不再需要的信息会被适当删除。请不要发送不必要的个人信息或照片。

除法律要求外，不会向第三方提供查询信息。电子邮件服务提供商根据自己的政策处理信息。

## 10.删除信息

您可以使用应用程序的删除功能删除材料和设计。当您删除应用程序时，本地数据将根据操作系统进行处理。小部件共享区域、设备备份、照片中导出的图像以及共享目的地的图像可能需要使用其自己的设置和功能单独管理或删除。

要请求访问、更正、删除或有关支持查询中提供的个人信息的其他适用权利，请在下面联系我们。我们将验证您的身份并根据适用法律做出回应。

## 11.安全

App围绕本地处理和存储进行设计，避免了不必要的外部传输。另请通过屏幕锁定和操作系统更新来保护您的设备，并管理您的备份和导出的图像。

## 12.本政策的变更

当功能或信息处理方式改变时，本政策会相应更新。重大变更将在应用内或本页面公布。法律要求取得同意时，我们会依法取得同意。
