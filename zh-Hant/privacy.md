# Locket 隱私權政策

生效日期：2026年10月8日。最後更新：2026年10月10日。

Reo Morishige(森重 玲生，「開發者」)下面描述如何在Locket(“應用程式”)中處理資訊。

## 1.概述

本應用程式可將去背照片、文字和手繪內容組合成小工具。照片處理和作品儲存均在裝置上完成。本應用程式不提供帳號註冊功能，也不會將照片、素材或作品傳送至開發者營運的伺服器。

該應用程式包括Google AdMob橫幅廣告和用於廣告同意的Google用戶訊息平台(UMP)。計劃提供付費無廣告選項，目前無法購買。

## 2.您的裝置上使用的信息

App在本地處理以下資訊以提供其功能：

- 您選擇或拍攝的照片，以及裁剪或剪切的圖像，以建立、顯示和編輯材料。

- 手繪圖片和筆畫資料，用於顯示、編輯和重複使用手繪素材。

- 材質和資料夾名稱、文字和設計設定（例如位置、顏色和樣式），以管理材料並編輯或重新開啟設計。

- 小部件圖像和設置，以在主螢幕和鎖定螢幕上顯示設計。

- 在顯示支援的效果時的設備運動，例如傾斜，以改變反射。運動不會保存為持續歷史記錄或發送給開發人員。

開發者無法查看或取得您裝置上的應用程式中儲存的照片、資料或設計。

## 3.儲存與裝置備份

應用程式資料儲存在您的裝置上。小部件圖像和設定也儲存在同一裝置上的應用程式及其小部件擴充共享的應用程式群組區域中。此共享不會向開發者發送訊息。

該App沒有獨立的雲端同步或線上備份功能。根據您的裝置設定和 Apple 的功能，可能會使用 iCloud 等服務進行裝置備份，以及透過 iCloud 照片同步匯出的照片。開發人員無權存取這些備份或您的照片庫。

## 4. 照片、相機與動作權限

使用作業系統的照片選擇器匯入照片；該應用程式處理您選擇的照片。當您選擇拍照時，會使用相機；當您選擇儲存匯出的設計時，會使用將影像新增至相片庫的權限。設備傾斜用於支援材質效果。

權限是透過作業系統請求的並且可以在裝置設定中改變。拒絕許可可能會導致相關功能無法運作。

## 5.外部連線與第三方服務

照片剪切在您的設備上處理。該應用程式與下述 Google 服務進行通訊以獲取廣告和同意。沒有整合單獨的行為分析服務。

在應用程式內瀏覽器中開啟使用條款或本政策會連接到 GitHub Pages。 GitHub 可能會處理 IP 位址、瀏覽器資訊和其他存取資訊以提供和保護網站。應用程式中儲存的照片、材料和設計不會發送到這些頁面。請參閱 [GitHub 的一般隱私權聲明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。

作業系統診斷、裝置備份和照片同步根據您的設定和[Apple的隱私權政策](https://www.apple.com/legal/privacy/en-ww/)進行處理。

## 6. Google AdMob 廣告與同意

該應用程式使用 Google 行動廣告 SDK 展示橫幅廣告，並根據您所在的地區和情況使用 Google UMP SDK 進行同意和隱私選擇。廣告出現在應用程式的介面內；它們不包含在主畫面或鎖定畫面小工具中，也不包含在從應用程式儲存或分享的影像中。

根據 SDK 設定、您的同意以及作業系統權限，IP 位址、裝置和應用程式資訊和識別碼、廣告展示和互動以及診斷等資訊可能會傳送給 Google。可以從 IP 位址推斷出大致位置。這些資訊用於廣告投放和衡量、詐欺預防、服務維護和改進以及同意管理。該應用程式不會將照片、剪紙材料、文字或設計內容或裝置動作傳遞給廣告 SDK。

目前實作請求非個人化廣告並且不請求應用程式追蹤透明度許可或存取IDFA的許可。發布者第一方 ID 個性化已停用。非個人化廣告仍涉及廣告投放、衡量和預防詐欺所需的資訊。

啟動時，應用程式向 UMP 要求更新的同意狀態，並在需要時顯示同意書。只有當 UMP 指示可以要求廣告時，廣告 SDK 才會啟動。當需要隱私選擇時，可以透過**設定→支援和法律→廣告隱私設定**開啟Google的隱私選項。更改同意或設定不一定會刪除已傳輸的資訊。

- [Google 隱私權政策](https://policies.google.com/privacy?hl=en)

- [Google Mobile Ads SDK 的 iOS 資料揭露說明](https://developers.google.com/admob/ios/privacy/data-disclosure)

- [個人化與非個人化廣告](https://support.google.com/admob/answer/7676680?hl=en)

## 7. 計畫中去廣告選項的購買資訊

計劃透過Apple的App Store在引入無廣告選項的版本中處理購買。 Apple 處理付款資訊；開發人員不取得信用卡號碼。該應用程式預計將處理啟用選項、驗證購買狀態和恢復購買所需的產品識別碼和交易或權利資訊。

此選項的條件會在購買前顯示。關閉廣告不會刪除已傳送的廣告資訊，也不會停止 Apple 的購買處理、裝置備份或類似服務。在導入購買功能前，本政策會更新，以說明實際實作中購買資訊的儲存與傳輸方式。

## 8.儲存與分享影像

當您選擇儲存或分享影像時，影像將被傳遞到您選擇的照片庫或共享目的地。您和所選服務負責管理導出的影像及其在目的地的使用。

## 9.支援查詢

如果您透過電子郵件聯絡我們，您的電子郵件地址、姓名（如果提供）、查詢內容和附件將被處理以回覆和解決問題。它們會在處理查詢所需的時間內保留，不再需要的資訊會被適當刪除。請不要發送不必要的個人資訊或照片。

除法律要求外，我們不會向第三方提供詢問資訊。電子郵件服務供應商會依其自身政策處理資訊。

## 10. 刪除資訊

您可以使用應用程式的刪除功能刪除材質和設計。當您刪除應用程式時，本機資料將根據作業系統進行處理。小部件共用區域、裝置備份、照片中匯出的影像以及共享目的地的影像可能需要使用其自己的設定和功能單獨管理或刪除。

若要要求存取、更正、刪除或有關支援查詢中提供的個人資訊的其他適用權利，請在下方聯絡我們。我們將驗證您的身份並根據適用法律做出回應。

## 11.安全

App圍繞著本地處理和儲存進行設計，避免了不必要的外部傳輸。請同時透過螢幕鎖定和作業系統更新來保護您的設備，並管理您的備份和匯出的映像。

## 12.本政策的變更

當功能或資訊處理方式改變時，本政策會相應更新。重大變更將在應用程式內或本頁面公布。法律要求取得同意時，我們會依法取得同意。
